# evals/

Avaliação de qualidade de extração de IA (golden set, rubrica, julgamento) contra dado
sintético/anonimizado. Nenhum dado real de cliente entra em `evals/datasets/` — ver
[`data/README.md`](../data/README.md).

Estrutura chega conforme o Golden Set (fase 3 do roadmap) for definido — não criada
antecipadamente.
