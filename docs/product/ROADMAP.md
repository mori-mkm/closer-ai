# Roadmap

Sequência de fases do produto. Ordem é intencional: cada fase depende de dado ou
aprendizado da anterior. Não é um cronograma com datas — é uma ordem de dependência.

1. **Segurança** — política de dados, sem PII no repo, autorização de uso de dados reais.
2. **Normalização das calls** — schema canônico de transcrição.
3. **Golden Set + Taxonomia** — amostra rotulada de referência, taxonomia de objeções/momentos.
4. **Call Intelligence** — extração estruturada (objeções, sinais, riscos, compromissos).
5. **CRM + Matching Call ↔ Deal** — ligar transcrição a oportunidade real.
6. **Outcome Intelligence** — comportamento de call → resultado no funil.
7. **Manager Intelligence** — visão agregada para gestores.
8. **Validação com clientes** — confirmar que o insight é acionável na operação real.
9. **Cortex / Realtime Copilot** — adiado até 6–8 estarem validados.
10. **Experimentation Engine** — testar mudanças de playbook de forma controlada.
11. **Playbook Learning** — atualizar playbook a partir de experimento.
12. **ROI Proof** — atribuição de resultado ao uso do sistema.

Estado atual de cada fase: [`docs/context/CURRENT_STATE.md`](../context/CURRENT_STATE.md).
