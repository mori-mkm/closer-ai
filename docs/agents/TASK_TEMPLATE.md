# Task

## Goal

O que precisa existir ao final, em uma frase.

## Why

Por que isso importa agora (link para fase do roadmap, se aplicável).

## Read first

Lista curta e explícita: quais documentos e arquivos o agent deve ler antes de codar.
Não "leia o projeto" — arquivos nomeados.

## Allowed files

Quais arquivos/diretórios podem ser criados ou editados. Tudo fora disso exige justificativa
explícita antes de tocar.

## Do not modify

Arquivos/diretórios explicitamente fora de escopo, mesmo que pareçam relacionados.

## Inputs

Dados/fixtures/contratos que a task recebe como dado. Se envolver dado real, a task está
malformada — usar fixture sintética.

## Expected output

Formato concreto do resultado (arquivo, função, schema).

## Acceptance criteria

Lista verificável, não subjetiva.

## Tests

Quais testes rodar, e quais testes novos a task exige.

## Blockers / assumptions

Premissas assumidas e o que bloquearia a entrega — para o agent reportar cedo, não descobrir
tarde.
